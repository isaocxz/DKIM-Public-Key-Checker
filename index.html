DKIM Public Key Checker

This tool checks the DNS public key record used for DKIM verification.
It does not verify the DKIM signature itself.

Choose a check method

Fetch the record from DNS or paste a TXT record directly.


Queries the selected public DNS resolver using RFC 8484 DNS over HTTPS (wire format). The requested FQDN is sent to that resolver.
If direct DoH access is unavailable, use TXT Record mode with output from your local DNS tools.

No DNS query is made. The input is processed only in your browser and is not sent to an external service. DNS-level properties such as TXT RR count and DNSSEC are not available in this mode.
